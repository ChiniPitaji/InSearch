# CampusBridge

A starting website for a platform that will connect students, companies, and colleges.

This first version is only a landing page. There is no login, no database, and no AI yet.

## How to run this on your computer

1. Open Terminal.
2. Go into the project folder:

```bash
cd /Users/jyotikumari/Downloads/student-job-platform
```

3. Start the website:

```bash
npm run dev
```

4. Open this address in your browser:

[http://localhost:3000](http://localhost:3000)

5. When you want to stop the website, go back to Terminal and press `Control + C`.

If you already ran `npm run dev` once, you do not need to install anything again. Just repeat steps 2 to 4.
